# 五疑戦 CP超強化監査

実施日: 2026-09-11

## 今回の強化

- CPの選択を単純な重み付きランダム中心から、高確率で最上位戦術を選ぶ高難度策士型へ強化。
- 15種類の秘密目標ごとに達成優先度を追加。死神の攻撃対象固定、殺人鬼の連続攻撃、観察者/追跡者の偵察、賭け師の偵察禁止、鉄壁の防御、瀕死/耐久者のHP管理、隠者の特殊カード禁止などを個別処理。
- 公開戦闘履歴から攻撃頻度、共同攻撃、防御、特殊使用、被害、対CP敵対度、公開上推定できる得点を記憶。
- 偵察で合法的に得たHP/通常手札を攻撃対象・カード指定へ利用。相手の非公開ポイント、秘密目標、未使用特殊カードは直接参照しない。
- 告発は公開行動から15目標の確率候補を作り、既知の重複不可情報と公開済み目標を使って候補を絞る。
- 特殊カードは終盤、HP、本人順位、既知の脅威、秘密目標を見て温存/使用を判断。
- ポイントが勝敗そのものなので無駄買いを抑えつつ、生存・秘密目標・逆転に必要な場合のみ通常/特殊カードを自動購入。
- 非公式同盟、信用、裏切りを記憶。約束相手から攻撃された場合は同盟解除・警戒・報復優先度を上げる。
- 人間の攻撃提案や同盟提案を行動案へ反映。CP同士も1ターン最大1往復の反応会話を行い、無限応答は防止。
- ローカル心理戦チャットの初動を高速化。ブラフ、攻撃誘導、共闘、裏切りへの指摘、終盤順位に応じた発言を追加。
- 外部AIは標準OFF。APIなし・料金0円でも戦略と心理戦チャットの全機能が動く。AI文章言い換えは任意機能としてのみ残す。

## 限界

「完全無欠」は保証できない。実際の5端末同時通信、Render本番ネットワーク障害、未知のブラウザ差、実ユーザーが作る予想外の会話すべてはローカル自動テストだけでは証明できない。

CPについては、外部生成AIや学習モデルを使わないという条件では、これ以上の強化は主にモンテカルロ探索・長期対戦ログ学習・大規模な会話意図解析の領域になる。現版はサーバー負荷、情報公平性、応答速度を維持したルールベースCPとして実用上かなり上限寄り。
