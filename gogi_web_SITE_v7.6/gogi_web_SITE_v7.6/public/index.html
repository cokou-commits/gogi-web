五疑戦

五疑戦ルール

5人固定・15ターン。 最終ポイントが最も高いプレイヤーが勝利。HPは5、0で脱落、復活なし。他人のポイントと秘密目標は試合中非公開。

1ターン

  1. 会話：最大100秒。全員が準備OKなら即終了。
  2. 行動選択：最大10秒。全員が行動確定なら即処理。
  3. サーバーで同時処理し、結果を表示。

放置対策：2ターン連続で一切操作がない場合は警告。3ターン連続で無操作の場合は自動脱落。カード指定を受けて指定カードを所持している場合、タイムアウトしても指定カードは自動で使用され、必要な対象等が未選択ならサーバーが自動補完します。

通常カード

  • 攻撃：1ダメージ。防御を上回ってダメージが発生すると攻撃成功+5P。
  • 防御：攻撃力1を防ぐ。
  • 偵察：相手のHP・キル数・通常カード種類/枚数を自分だけ確認。特殊カード・ポイント・秘密目標は見えない。
  • 告発：相手の秘密目標を当てる。成功+30P、対象の秘密目標を無効化。
  • 回復：HP+2（最大5）。

特殊カード

  • 完全防御：全攻撃を防ぎ、攻撃者人数×5P。
  • 無効：指定相手のそのターンの通常/特殊行動を無効化。
  • カード指定：相手の次ターン通常カードを指定。異なる指定が同時に競合すると対象は次ターン行動なし。
  • ポイント泥棒：5〜25Pを指定して奪う。同じ相手への同時泥棒は5P単位で公平配分。
  • 2倍カード：攻撃2 / 防御2 / 偵察2人 / 告発2回 / 回復+4。

会話中にできること

全体/個別チャット、カード購入、通常/特殊カード譲渡、5・10・15ターンのポイント譲渡、行動の仮選択。同盟・嘘・ブラフ・裏切りはゲーム上の戦術として自由。

購入価格

攻撃20P / 防御20P / 偵察20P / 告発30P / 回復40P / 特殊カード（ランダム）50P。通常カード購入は1ターン1回、特殊カード購入は1試合1回。

主な得点

攻撃成功+5P / 単独キル+20P / 共同キル各+10P / 告発成功+30P / 秘密目標+35P / 15ターン生存+50P。第15ターン中の新規得点は2倍（生存+50Pは対象外）。

秘密目標15種を見る
  1. 観察者：4人全員を1回以上偵察
  2. 追跡者：同じ相手を2回以上偵察
  3. 賭け師：一度も偵察せず告発成功
  4. 贈与者：ポイント譲渡成功
  5. 殺人鬼：3ターン連続で有効な攻撃行動
  6. 死神：試合を通して攻撃対象を1人だけに絞り、その相手へ2回以上攻撃
  7. 処刑者：単独キル
  8. 共犯者：共同キル2回
  9. 復讐者：自分を攻撃したことがある相手をキル
  10. 鉄壁：攻撃を防いだターン3回
  11. 瀕死：第15ターン終了時、生存かつHP1
  12. 耐久者：累計4ダメージ以上受ける
  13. 隠者：特殊カード未使用で15ターン生存
  14. 詐欺師：5ターン連続で構造化情報発言がすべて嘘
  15. 正直者：5ターン連続で構造化情報発言がすべて真実

勝敗

同点時は、キル数 → 告発成功数 → 有効な秘密目標達成数 → 生存ターン数 → 残りHP の順で判定。すべて同じなら同順位。

詳細な秘密目標・得点・特殊処理はサーバー側の正式ルールに従います。
