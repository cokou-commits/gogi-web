# 五疑戦 (GOGISEN) — Web版 v7.6 / CPなし本番版

5人制・15ターンのオンライン心理戦カードゲーム「五疑戦」の現行実装です。2026-09-12の最終監査版で、ルール・UI・通信・再接続・秘匿情報・経済操作・終了処理をサーバー主導で統一しています。

> 人間5人固定です。CP・外部AI・自動補充はありません。

## 現行仕様の要点

- 5色: 赤 / 青 / 黄 / 緑 / 紫
- 初期HP5、最大HP5、HP0で脱落、復活なし、初期0P
- 会話＋行動選択は最大10分、結果確認は最大1分
- 通常カード: 攻撃 / 防御 / 偵察 / 告発 / 回復
- 特殊カード: 完全防御 / 無効 / カード指定 / ポイント泥棒 / 2倍
- 通常防御は自分または他の生存者を守れる。完全防御は自分専用
- 回復は自分または他の生存者を+2、2倍併用時は同じ対象を+4
- 購入価格: 攻撃15 / 防御15 / 偵察15 / 告発25 / 回復35 / 特殊45P
- 通常カード購入は各ターン回数制限なし。特殊カード購入は1試合1回
- 告発は脱落者も対象に選択可能（自分自身は不可）
- 独立したポイント譲渡・カード譲渡は廃止。承認制の交換へ統一
- 公開契約は25P刻み、複数人参加、達成者1人あたり契約P÷5、余剰返却。提示件数制限なし（同一ターン・同時複数件可）
- 1位予想は第3/6/9ターンのいずれか1回。10倍 / 5倍 / 2.5倍
- 1位予想は試合中非公開、試合終了時に全員分を公開
- 秘密目標10種、報酬25P
- 第5/10/15ターン開始時に生存者へ+5/+10/+15P。いずれも2倍なし
- 第15ターン終了まで生存で+50P。2倍なし
- 第15ターンは攻撃成功・防御成功・告発成功/失敗・完全防御等の新規得点/減点のみ2倍
- 各ターンの公開結果はなし。本人には成功/失敗、偵察、HP純増減、ポイント純増減だけ表示
- BGMなし。SE・通知音のみ。全体/個別チャット、交換、公開契約に通知あり
- 個別チャットは色ごとに履歴を分離
- 最終画面は賭け判定前順位 → 1位予想結果 → 正式最終順位を追加操作なしで表示

詳細な確定ルールは `RULES.md`、最終決定事項は `RULE_DECISIONS.md` を参照してください。

## 実装上の保護

- サーバーをゲーム状態の正とし、クライアント入力を検証
- フェーズ世代番号で古い操作を拒否
- 経済操作に操作IDを付け、ACK再送時の二重処理を抑止
- 交換提案側の資産をエスクローし、拒否・取消・期限切れで返却
- 交換提案は同時件数制限なし。同一相手への複数提案・複数相手への並行提案に対応
- 交換承認は必要資産を検証・確保してから操作IDを確定
- 秘密目標欠損はstate送信前に自動修復
- 他人のHP/ポイント/手札/特殊/秘密目標/賭け情報を必要以上にsnapshotへ含めない
- 個別チャットは当事者だけへ配信
- 公開結果廃止後の内部対戦ログはクライアントへ配信しない
- CSP / HSTS(本番) / frame拒否 / no-referrer / Permissions-Policy
- Socket総接続数・ルーム数・入力長・操作頻度を制限
- ルームコードと初期配布に暗号学的乱数を使用
- 終了画面描画後はWebSocketを解放

## パフォーマンス

5人固定のため、ゲーム処理はサーバー内の小さな同時解決です。通常stateは軽量化し、静的カード/目標定義は初回stateだけ、チャットは差分配信、内部対戦ログは送信しません。カード画像はリビジョンURL＋長期キャッシュ、待機中に先読みします。

現在の状態は単一Nodeプロセスのメモリ保持です。最初の小規模公開では1インスタンスを前提とし、水平分散や再起動復元は意図的に未実装です。

## 起動

Node.js 24.21.xを推奨します。`package.json` は `>=24.21.0 <25` を指定しています。

```bash
npm install
npm run verify
npm start
```

本番では `.env.example` を基に、少なくとも `NODE_ENV=production` と正しい `ALLOWED_ORIGINS` を設定してください。

## テスト

この最終ビルドで確認するコマンド:

```bash
npm run verify
npm run stress
```

監査結果は `AUDIT.md`、実行した最終テストは `FINAL_TEST_REPORT_20260912.md` に記録しています。

## 意図的に対象外

- 課金 / 参加費 / 賞金
- ボイスチャット
- 英語・海外対応
- 恒久アカウント / 永続戦績
- 複数サーバー水平分散
- サーバー再起動からの進行中試合復元

これらは現在の「日本向け・無料・5人対戦」の完成条件には含めていません。


## 2026-09-12 偵察対象更新

- 偵察は自分以外の生存者・脱落者を対象にできる。
- 2倍カードの2人目偵察も同様。
- 攻撃・防御・回復など他カードの対象条件は変更しない。
