# 五疑戦 (GOGI) — Web版 v7.6

5人固定・15ターン制のオンライン心理戦カードゲーム「五疑戦」のWeb実装です。

> このファイルは **CP確認テスト版** です。一般公開用はCPなし版を使用してください。

## このZIPの位置づけ

これは旧MVPではなく、現在の仕様をサーバー主導で実装し、バグ・競合・再送・再接続・スマホUIまで監査した**Workへ渡す最終開発ベース**です。


v7.5までに、v7.3以降の追加監査で見つかった通信・再接続・スマホ描画・タイムアウト境界・公開運用上の問題を修正しています。state/ログ/チャットの差分配信、Storage例外耐性、再接続の冪等化、プレイヤー単位レート制限、サーバー絶対締切、モバイルのsafe-area/描画負荷対策、ポイント譲渡UI軽量化を反映しました。さらに最終監査で、**プライベートルームが5人揃っても自動開始しない重大漏れ**と、**終了画面を開きっぱなしにした際にWebSocket接続枠を占有し続ける問題**を発見して修正しています。ゲームルール自体は変更していません。

本番ターゲットはNode.js 24系、依存はExpress 5.2.1 / Socket.IO 4.8.3に固定しています。ただし、この監査コンテナ自体はNode.js 22.16.0で、外部通信の `npm install` がタイムアウトしたため、Node.js 24 + 実依存を読み込んだ起動確認はWork/本番候補環境で再実施が必要です。

ただし「バグ0」を数学的に保証するものではありません。ネットワーク依存の本物の5ブラウザE2E、iPhone/Android実機、依存パッケージ監査、本番負荷試験はネットワーク接続可能な実環境で最後に行う必要があります。未確定のゲームルールは `RULE_DECISIONS.md` に分離しています。

## 実装済み

- 5人固定 / 日本語のみ / 15ターン
- 公開ランダムマッチ
- プライベートルームは5人目参加直後に自動開始
- 8文字コードのプライベートマッチ（紛らわしい I/O/0/1 を除外）
- テキストチャット（全体 / 1対1個別）
- 会話＋行動選択 最大10分 / 全生存者が「次へ」で即処理
- 結果表示 最大1分 / 接続中の人間全員が「次へ」で即次ターン
- 会話中から行動を仮選択
- 仮選択更新は差分ACK方式で同期し、高頻度操作時の帯域・再描画負荷を抑制
- 初期HP5 / 最大5 / 復活なし / 初期0P
- 正式初期手札（攻5 / 防5 / 偵5 / 告3 / 回1）
- 特殊5種を開始時に重複なしで1枚ずつ配布
- 攻撃 / 防御 / 偵察 / 告発 / 回復
- 完全防御 / 無効 / カード指定 / ポイント泥棒 / 2倍カード
- 通常購入1ターン1回 / 特殊購入1試合1回
- ポイント譲渡・カード単体譲渡は廃止し、資産移動は承認制の交換へ統一
- 交換（双方とも0P・カード0枚を選択可能。片側だけ資産を出す無償提供も相手承認で成立。両側完全空は不可）
- 公開契約（次ターン条件・25P刻み契約ポイント・複数人参加・余剰返却・自動判定）
- 第10ターン以降は本人にだけ現在順位を公開（5人全員基準、同点は「同率」、生存人数は別表示）
- 10種類の秘密目標と判定
- 第15ターン新規得点2倍
- 生存+50P
- 正式タイブレーク
- 切断 / 更新からのセッション復帰
- ホーム閲覧だけではWebSocketを開かず、参加/復帰時だけ接続
- 購入・交換の秘匿stateは関係者だけへ差分配信
- 最後の「次へ」では冗長な中間stateを省略
- ゲーム終了後は最終結果を保持したままWebSocket接続を解放
- 同じ復帰トークンの別タブ乗っ取り防止
- 同一ブラウザIDによる基本的な二重参加防止（アカウントなしで可能な範囲）
- 8文字・約40bitのプライベートルームコード
- 他人個別の「次へ」状態を伏せ、集計人数だけ表示
- Socketイベントのサーバー側検証
- フェーズ世代番号による古い通信拒否
- 購入 / 交換 / 公開契約の操作IDによるACK再送の二重処理防止
- Socket総接続上限 / ルーム上限 / 終了ルーム清掃（Socket.IO membershipも解放）
- CSP / HSTS / XSSを避けるDOM描画 / 入力長制限 / レート制限
- 暗号学的乱数による初期配布
- スマホ優先UI（主要な小型操作は44px以上、会話・行動選択を1画面に統合し、購入・交換・偵察も同一画面オーバーレイで操作可能）
- Dockerfile / health endpoint
- ゲームエンジン・回帰・静的・シミュレーションテスト

## 起動

Node.js 24以上（本番はNode.js 24 LTS推奨）。

```bash
npm install
npm run verify
npm start
```

開発時は `NODE_ENV=development` を使えます。本番では `.env.example` を参考に `ALLOWED_ORIGINS` を実公開URLへ設定してください。

ブラウザ:

```text
http://localhost:3000
```

ヘルスチェック:

```text
GET /health
```

## 5人ローカルテスト

PC 1台でも、Chromeプロフィールを5つ用意するか、複数ブラウザ / シークレットを組み合わせれば5接続できます。

**同じ通常タブを複製して同じ復帰トークンを奪い合う挙動は防止しています。** 別プレイヤーとして試す場合は別ブラウザプロフィールを使ってください。

## サーバー前提

進行中のゲーム状態は現在サーバーメモリを正としています。

- 初期公開：Node.js **1インスタンス**
- サーバー再起動：進行中試合は失われる
- 複数インスタンス：そのまま水平分散しない

水平分散・再起動復元まで必要になったら Redis等の共有Socket.IOアダプタ + 共有状態ストアを追加します。小規模公開の最初からこれを入れると複雑性と障害点が増えるため、現版では意図的に入れていません。

## 1位予想ギャンブル

第3・6・9ターンのいずれかで1試合1回。5P刻みで所持Pまで賭け、第3ターンは的中時10倍、第6ターンは5倍、第9ターンは2.5倍。払戻し前順位で的中判定後、払戻しを反映して最終順位を再計算する。試合中は賭け先・賭け額・賭けたターンを本人以外へ送信しない。試合終了時に全員分の予想相手・賭けP・賭けターン・倍率・的中/外れ・払戻しを全員へ公開する。


## 2026-09-12 取引・公開契約更新
- ポイント譲渡・カード単体譲渡の独立機能は廃止。資産移動は交換に統一。
- 交換は双方ともポイント0P・カード0枚を選択可能。片側だけ資産を出す提案も相手承認で成立。両側とも0P・0枚の空交換のみ不可。
- 公開契約は第1〜14ターンに提示し、次ターンの条件達成を自動判定する。条件・契約ポイント・参加者は全員へ公開する。
- 交換・公開契約はいずれも通常カード行動やターンを消費しない。
- 1位予想は試合中完全非公開、試合終了時に全員分を公開。
