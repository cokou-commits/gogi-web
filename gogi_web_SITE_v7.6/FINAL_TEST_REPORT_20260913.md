## 今回の最終監査で追加修正した項目

1. 五戯チップ残高をクライアント申告制からサーバー内台帳へ変更。localStorage改変による任意残高注入を防止。
2. チャージ判定もサーバー側へ移し、0残高のみ許可・対戦参加中は拒否。
3. 五戯チップ台帳に最大件数と30日未使用掃除を追加。対戦中ブラウザは退避対象から除外。
4. 決済済み公開契約をライブ配列から除去し、提示件数無制限でも不要メモリを蓄積しないよう変更。
5. 公開契約の旧「前/次ターン」コメント・分岐ノイズを整理し、現仕様の提示ターン判定へ統一。
6. 特殊カードの内部イベントコメントを、対戦中非公開・終了後履歴公開の現仕様へ修正。
7. 日次チップ配布廃止後に残っていた `chipLastGrantDate` を削除。
8. 過去更新メモ・pre_finalバックアップを最終配布物から除外し、現行文書だけを残した。
9. 公開契約金額ヘルパーを境界値に対して硬化し、NaN/負値/不正倍率の伝播を防止。
10. 五戯チップ不正賭け額・残高不足、カード指定タイムアウト補完、secretState単独欠損などの境界テストを追加。
11. `npm run check` に `src/contracts.js` / `scripts/stress.js` を追加し、配布後の自己検証対象を拡張。
12. 公開契約の条件対象として提示者自身の色も指定可能に変更。攻撃/告発を含め、UIとサーバー検証を統一。提示者本人は従来どおり報酬参加者にはならない。
13. 全カード購入価格を5P引き下げ（攻撃10 / 防御10 / 偵察10 / 告発20 / 回復30 / 特殊40P）。CPの購入・交換価値評価も共通定数参照のため新価格へ自動追従。
14. 初期回復カードは1枚を維持。価格低下後に初期2枚へ増やすと生存力が過剰に上がるため、現時点では変更しない。
15. 公開契約自己対象・購入価格改定を含む既存回帰テストを維持。
16. 準備OK中の接続済み人間へ交換提案が届いた場合、準備OKを自動解除して承認/拒否を必須化。回答後は本人が再度「次へ」を押す仕様に変更。
17. 公開契約と交換通知を固定通知＋トーストの二重表示にし、準備OK中やツール画面表示中でも見落としにくくした。
18. 公開契約は自動参加かつ件数無制限のため準備OKを強制解除しない。契約連打による進行妨害を防ぎ、必要な場合だけ本人が「戻る」で行動変更できる。
19. 上記2仕様の静的/回帰テストを追加。
