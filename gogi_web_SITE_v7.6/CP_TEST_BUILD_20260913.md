# CP確認テスト版

現行ルールを基準に、実機確認用CPを追加したテストバリアントです。

- 待機室の「CPで空き枠を補充」で5人まで補充
- CPは外部AI/APIを使用せず、サーバー内ロジックだけで合法手を自動選択
- CPは通常カード・特殊カードを使用
- CPは自分の秘密目標に応じて、偵察・攻撃・告発・防御などの選択傾向を変える
- 「隠者」は特殊カードを使わない、「耐久者」は回復を避ける、「無防備」は防御を避ける等、秘密目標条件を壊さないよう行動する
- CPもポイントがあれば通常カード・特殊カードを購入する
- CPも交換提案を出し、人間からCPへの交換提案にも自動回答する
- CPも公開契約を匿名で提示し、公開契約へ自動参加する
- CPも第3/6/9ターンの1位予想へ参加可能
- CPは結果確認を自動完了扱いにし、人間1人でも15ターンを進行可能
- 五戯チップ有り対戦ではCPにもテスト用残高を付与し、部屋の同額賭け条件を満たす
- CPはチャットを自動送信しない
- CPなし版の得点・カード・公開契約・五戯チップ等の基本ルールは変更しない
