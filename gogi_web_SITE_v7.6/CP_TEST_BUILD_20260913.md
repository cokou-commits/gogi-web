# CP確認テスト版

現行CPなし版と同一仕様を基準に、実機確認用CPだけを追加したテストバリアントです。

- 待機室の「CPで空き枠を補充」で5人まで補充
- CPは外部AI/APIを使用せず、サーバー内で合法な通常/特殊カードを自動選択
- CPは結果確認を自動完了扱いにし、人間1人でも15ターンを進行可能
- 人間からCPへの交換提案は、CPが必要資産を持つ場合に自動承認
- 人間が公開契約を出すと、条件上参加可能なCPが自動参加
- CPも第3/6/9ターンに所持Pがあれば1位予想を行うことがある
- 五戯チップ有り対戦ではCPにもテスト用残高を付与し、部屋の同額賭け条件を満たす
- CPなし版のゲーム仕様・得点・カード・五戯チップ仕様は変更しない
