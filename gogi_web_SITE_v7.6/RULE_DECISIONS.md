# 五疑戦 v7.6 — 現行ルール決定事項

2026-09-12時点の確定仕様。未確定ルールの一覧ではなく、現在の実装と一致させるための決定記録。

- 5人固定・人間のみ。CP機能なし。
- 15ターン、初期HP5・最大HP5、HP0で脱落、復活なし、初期0P。
- 秘密目標は10種類から5人へ重複なし配布。報酬+25P、第15ターンでも2倍なし。
- 攻撃成功+10P、防御成功+10P、告発成功+25P、告発失敗-10P。単独/共同キル追加点なし。
- 第15ターンは攻撃成功・防御成功・告発成功/失敗・完全防御などの新規得点/減点だけ2倍。秘密目標、生存+50P、ターン開始ボーナス、ポイント泥棒、交換、秘密目標得点没収は2倍にしない。
- 第5ターン開始時+5P / 第10ターン開始時+10P / 第15ターン開始時+15Pを、その時点の生存者へ固定付与。
- 第15ターン終了まで生存したプレイヤーへ+50P。
- 通常防御は自分または他の生存者を対象にできる。完全防御は自分専用。
- 回復は自分または他の生存者を対象にできる。通常+2、2倍併用+4、最大HP5、復活なし。
- 情報発言機能は廃止。チャットは全体と色別1対1個別を分離表示する。

## 秘密目標10種

1. 観察者：3ターン連続で偵察
2. 追跡者：同じ1人を5回偵察
3. 賭け師：告発相手を一度も偵察せず、その相手への告発成功
4. 殺人鬼：3ターン連続で攻撃
5. 死神：同じ1人を5回攻撃
6. 鉄壁：防御を3回成功
7. 耐久者：回復を使わない
8. 瀕死：累計5ダメージ以上を受けて生存
9. 無防備：防御を使わない
10. 隠者：特殊カードを使わない

耐久者・無防備・隠者は、第15ターン生存で条件維持なら達成。何ターン目でも未使用のまま脱落した場合は脱落時点で達成。

## 交換

- ポイント譲渡・カード単体譲渡の独立機能は廃止し、資産移動は承認制の交換へ統一。
- 双方ともポイント0Pまたは5P刻み、カード0枚または1枚を選択できる。
- 片側だけが資産を出す提案も相手承認で成立。双方完全空の交換のみ禁止。
- 提案者資産はエスクローし、拒否・取消・ターン終了期限切れなら返却。
- 交換は通常カード行動やターンを消費しない。
- 交換提案の同時件数に上限を設けない。同じ相手への複数提案・複数相手への並行提案を許可する。提案者側資産は各提案ごとにエスクローして二重使用を防ぐ。

## 公開契約

- 第1〜14ターンに提示件数制限なし。同じターンに複数件・同時に複数件提示可能。契約ポイントは各契約ごとに所持P以内の25P刻みで全額を提示時に保留。
- 25Pなら達成者1人5P、50Pなら1人10Pのように、達成者1人あたり契約ポイント÷5を配布。
- 契約を出した本人以外の複数人が参加可能。条件・契約ポイント・参加者は公開。
- 条件は「指定色を有効攻撃」「提示色を攻撃しない」「提示色へ防御カードを使う」「指定色を告発（成功/失敗どちらでも可）」の4種類。
- 次ターン終了時に参加者ごとに判定。達成者分だけ配布し、未達成/未参加分などの余りは提示した色へ返却。
- 参加者0人のまま提示ターン終了なら全額返却。参加者0人の間だけ提示者が取消可能。
- 判定ターン開始前に条件の対象色/提示色が既に脱落して条件が成立不能・無意味なら契約を取消し、全額返却。
- 公開契約は通常カード行動やターンを消費しない。

## 1位予想

- 第3・6・9ターンのいずれかで1試合1回。5P刻み、所持Pまで。
- 第3ターン10倍 / 第6ターン5倍 / 第9ターン2.5倍。
- 賭けPは即時差引き。払戻し前順位で的中判定後、払戻しを加えて正式最終順位を再計算。
- **試合中**は賭け先・賭け額・賭けターン・倍率・的中/外れ・払戻しを本人以外へ非公開。
- **試合終了時**に全員分を全員へ公開。

## 結果・情報保護

- 各ターンの公開結果は廃止。本人の成功/失敗、偵察結果、HP純増減、ポイント純増減だけを本人へ表示。
- 攻撃・特殊カード・告発・交換内容などの内部対戦ログはクライアントへ送らない。
- 公開契約は公開機能なので提示・参加・受付終了/期限切れ・取消・精算を通知する。
- 交換は関係者だけへ提案/拒否/取消/期限切れ/成立を通知する。
- 1位予想は試合中秘匿し、ゲーム終了時だけ全員公開する。

- 告発対象・偵察対象は脱落者も選択可能。防御は対象を自動選択せず、毎回明示選択する。
