# 五疑戦 v7.6 — 現行ルール決定事項

2026-09-13時点の確定仕様。未確定ルールの一覧ではなく、現在の実装と一致させるための決定記録。

- 5人固定。人間のみの5人対戦に加え、待機中の人間全員が同意した場合は空き枠をCPで補充できる。CPは正式実装で、チャット以外の主要ゲーム機能を使用する。
- 15ターン、初期HP5・最大HP5、HP0で脱落、復活なし、初期0P。
- 秘密目標は各プレイヤーが10種類から独立ランダム抽選し、重複を許可する。報酬+25P、第15ターンでも2倍なし。
- 攻撃成功+10P、自分への防御成功+10P、他人への防御成功+15P、他人への回復成功+10P、告発成功+25P、告発失敗-10P。単独/共同キル追加点なし。
- 第15ターンは攻撃成功・防御成功・他人回復成功・告発成功/失敗・完全防御などの新規得点/減点だけ2倍。秘密目標、生存+50P、ターン開始ボーナス、ポイント泥棒、交換、秘密目標得点没収は2倍にしない。
- 第5ターン開始時+5P / 第10ターン開始時+10P / 第15ターン開始時+15Pを、その時点の生存者へ固定付与。
- 第15ターン終了まで生存したプレイヤーへ+50P。
- 通常防御は自分または他の生存者を対象にできる。完全防御は自分専用。
- 同じ対象へ複数人が通常防御した場合、その対象に有効な攻撃が1以上あり通常防御で1以上を防げれば、攻撃数より防御人数が多くても防御参加者全員を成功扱いにする。完全防御成立時は通常防御の成功得点は発生しない。
- カード指定で固定した通常カード＋対象の成功得点は指定者へ移す。告発失敗などの失敗減点は実行者本人が受ける。
- カード指定は「相手・通常カード・そのカードを使う対象」まで指定する。指定解決時点で相手が指定カードを持っていなければ失敗し、カード指定は使用者へ返却する。
- カード指定で固定した使用対象が次ターンまでに脱落・告発済み化などで無効になった場合、別対象へ勝手に振り替えず強制通常行動を不成立とし、その通常カードは消費しない。
- 回復は自分または他の生存者を対象にできる。通常+2、2倍併用+4、最大HP5。同ターンに攻撃と重なった場合は回復を先に処理。脱落者の復活なし。
- 情報発言機能は廃止。チャットは全体と色別1対1個別を分離表示する。

## 秘密目標10種

1. 観察者：3ターン連続で偵察
2. 追跡者：同じ1人を5回偵察
3. 賭け師：告発相手を一度も偵察せず、その相手への告発成功
4. 殺人鬼：3ターン連続で攻撃
5. 死神：同じ1人を5回攻撃
6. 鉄壁：防御を3回成功
7. 耐久者：回復を使わない
8. 瀕死：累計5ダメージ以上を受けて生存
9. 無防備：防御を使わない
10. 隠者：特殊カードを使わない

耐久者・無防備・隠者は、第15ターン生存で条件維持なら達成。何ターン目でも未使用のまま脱落した場合は脱落時点で達成。

## 交換

- ポイント譲渡・カード単体譲渡の独立機能は廃止し、資産移動は承認制の交換へ統一。
- 双方ともポイント0Pまたは5P刻み、カード0枚または同一種類1〜99枚を選択できる。
- 片側だけが資産を出す提案も相手承認で成立。双方完全空の交換のみ禁止。
- 提案者資産はエスクローし、拒否・取消・ターン終了期限切れなら返却。
- 交換は通常カード行動やターンを消費しない。
- 交換提案の同時件数に上限を設けない。同じ相手への複数提案・複数相手への並行提案を許可する。提案者側資産は各提案ごとにエスクローして二重使用を防ぐ。

## 公開契約

- 第1〜15ターンに提示件数制限なし。同じターンに複数件・同時に複数件提示可能。使用Pは各契約ごとに所持P以内の20P刻みで全額を提示時に保留。すべて提示したそのターン終了時に判定。
- 通常は20Pなら達成者1人5P、40Pなら1人10Pのように達成者1人あたり使用P÷4を配布。第15ターン判定は2倍（20P→1人10P、40P→1人20P）。
- 提示と同時に条件上参加可能な生存者が自動参加する。提示者本人は参加者から除外するが、条件対象として提示者自身の色を指定することは可能。さらに、自分自身を対象にできない「攻撃・攻撃しない・告発」の指定対象者は参加者から除外。条件と1人あたり報酬額は公開するが、提示者・参加者の色と使用Pは公開しない。
- 条件は「指定色を有効攻撃」「指定色を攻撃しない」「指定色へ防御カードを使う」「指定した生存色へ回復カードを使う」「指定色を告発（成功/失敗どちらでも可）」の5種類。
- すべて提示したそのターン終了時に参加者ごとに判定。達成者分だけ配布し、未達成/未参加分は提示した色へ返却。
- 自動参加の対象者が0人なら全額返却。提示後の手動取消は行わない。
- 攻撃・攻撃しない・防御・回復の対象は提示時点の生存者から選択可能で、提示者自身も条件対象に指定できる。告発対象も提示者自身を含む生存者・脱落者から選択できるが、既に告発成功済みの相手は選択不可。
- 公開契約は通常カード行動やターンを消費しない。

## 1位予想

- 第3・6・9ターンのいずれかで1試合1回。5P刻み、所持Pまで。
- 第3ターン10倍 / 第6ターン5倍 / 第9ターン2.5倍。
- 賭けPは即時差引き。払戻し前順位で的中判定後、払戻しを加えて正式最終順位を再計算。
- **試合中**は賭け先・賭け額・賭けターン・倍率・的中/外れ・払戻しを本人以外へ非公開。
- **試合終了時**に全員分を全員へ公開。

## 結果・情報保護

- 各ターンの公開結果は廃止。本人の通常カード成功/失敗、完全防御・カード指定・ポイント泥棒の成功/失敗、偵察結果、HP純増減、ポイント純増減だけを本人へ表示。
- 攻撃・特殊カード・告発・交換内容などの内部対戦ログはクライアントへ送らない。
- 公開契約は公開機能だが、提示通知・精算通知は匿名で行い、提示者・参加者の色は通知しない。
- 交換は関係者だけへ提案/拒否/取消/期限切れ/成立を通知する。
- 1位予想は試合中秘匿し、ゲーム終了時だけ全員公開する。

- 告発対象・偵察対象は脱落者も選択可能。ただし告発成功済みの相手は告発対象から除外する。防御は対象を自動選択せず、毎回明示選択する。

- 完全防御の得点は攻撃者人数×10P。第15ターンはこの得点も2倍。
- 購入価格は攻撃10P / 防御10P / 偵察10P / 告発20P / 回復30P / 特殊カード40P。特殊カードはランダム購入で、所持ポイントの範囲なら回数制限なし。


## 五戯チップ

- 五戯チップは無料ゲーム内チップ。課金購入・譲渡・換金・景品交換は行わない。
- 初期100,000五戯チップ。所持0のときだけ100,000チャージ可能。日付による自動配布なし。
- 五戯チップ残高はクライアント申告値を信用せず、実行中サーバー内のbrowserId別台帳を正とする。ブラウザ側保存は表示キャッシュのみ。
- 公開マッチは0または100刻みで賭け額を選び、同額の5人だけをマッチング。
- プライベートマッチは部屋主設定額を全参加者へ強制。所持不足なら参加不可。
- 0チップ対戦を常設し、賭けなしで遊べる。
- 対戦開始時に全員から設定額を差し引き、その時点のサーバー台帳へ同期する。終了時の賞金反映後もサーバー台帳へ同期する。
- 最終順位1位賞金枠 = 賭け額×2.5。最終1位が同率なら均等分配。
- 1位予想成績1位賞金枠 = 賭け額×2.5。的中者のうちゲーム内払戻しP最大を予想成績1位とし、同率なら均等分配。
- 1位予想の的中者がいない、または参加者がいない場合は、予想賞金枠を第2順位発表（払戻し後の最終順位）の1位へ配分。同率1位なら均等分配。
- 同じプレイヤーが両方を単独1位なら合計賭け額×5。

## CP補充開始

- CPは正式実装。待機室でCP補充を使う場合、参加中の人間プレイヤー全員の同意が揃ってから残り枠をCPで補充して開始する。

- 公開契約条件に「指定した生存色へ回復カードを使う」を追加。契約判定は実回復量ではなく、有効な回復カード使用を基準とする。


## 2026-09-13 最終調整（公開契約自己対象・購入価格）
- 公開契約は提示者自身の色も条件対象に指定できる。提示者自身は報酬参加者にはならない。
- 全カードの購入価格を従来より5P引き下げ、攻撃10P / 防御10P / 偵察10P / 告発20P / 回復30P / 特殊40Pとする。
- 初期回復カードは1枚を維持する。購入価格を30Pへ下げたため補充余地は増えており、初期2枚にすると総HP回復余力が大きく増えて攻撃・脱落圧を弱めすぎるため、現時点では増量しない。
