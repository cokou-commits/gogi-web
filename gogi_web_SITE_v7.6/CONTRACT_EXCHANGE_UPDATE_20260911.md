# 公開契約・交換・1位予想非公開化 更新（2026-09-11）

## 交換
- カード単体の譲渡を廃止。
- ポイント⇔カード、カード⇔カード、ポイント＋カード等の交換を追加。
- 双方が1つ以上の資産を出す必要があり、受け手承認で同時成立。
- ポイントは5P刻み。提案者側の提示資産は承認待ち中に保留し、拒否・取消・期限切れなら返却。
- カード指定中の最後の指定カードは交換不可。
- ターン消費なし。

## 公開契約
- 第1〜14ターンに5P刻みの報酬を提示。
- 条件・報酬・受諾者を全員へ公開。
- 条件は「次ターンに指定相手を有効攻撃」または「次ターンに契約主を攻撃しない」。
- 受諾者は1人。次ターン終了時に自動判定。
- 達成で受諾者へ報酬、未達/未受諾で契約主へ返却。
- 無効カードで消された攻撃は有効攻撃として数えない。
- ターン消費なし。

## 1位予想
- 第3・6・9ターンのみ、1試合1回。
- 第3ターン10倍 / 第6ターン5倍 / 第9ターン2.5倍。
- 賭け先・賭け額・賭けターン・的中/外れ・払戻し情報は本人以外へ非公開。
- 払戻し前順位で判定し、払戻し後に最終順位を再計算。
