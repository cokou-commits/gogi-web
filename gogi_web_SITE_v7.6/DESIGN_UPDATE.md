# 五疑戦 Premium UI Update

- ゲームロジック、通信仕様、得点、カード効果は変更していない。
- ブランドカラーを黒／グラファイト＋ベージュ系アイボリーへ統一。
- 「五疑戦」タイトルを明朝系・ベージュメタリック調へ刷新。
- 背景、パネル、見出し、ボタン、フォーム、チャット、待機室、結果、ルールモーダルを全面再設計。
- 既存のシンプルなカード画像と残り枚数バッジを維持し、選択状態・枠・影のみ調整。
- 偵察UIに「HP・キル数・通常カードのみ判明」を常設し、特殊カードが非公開であることを明確化。
- スマホでは高コストな全面backdrop-filterとノイズを無効化し、視覚品質と操作性能を両立。
- faviconも黒＋ベージュへ統一。

## 最終UI監査追補
- 現行フェーズ表示を『会話制限時間 / 結果発表』へ統一。会話と行動選択は同じ10分画面で並行して行い、旧バトル専用フェーズは廃止。
- 偵察結果を通常カード画像・枚数・HP・キル数の専用画面へ変更し、特殊カード・ポイント・秘密目標は非公開のまま維持。
- 結果発表を公開結果 / 自分だけの結果 / ポイント増減に分離。
- 公開ディレクトリに残っていた旧UIバックアップ3ファイルを削除。
- 偵察結果DOMの不要な再構築を抑制し、最新結果を自動展開。
- 結果発表は最大1分。接続中の人間全員が「次へ」を押せば早送りでき、次ターン後も「直前の結果」から公開結果・個別結果・ポイント増減を再確認できる。
- 静的なカード定義・秘密目標定義は同一Socketの初回stateだけ送信し、高頻度の状態同期を軽量化。
- チャット等の文字列からUnicode双方向制御文字を除去し、表示順偽装によるUI混乱を抑止。
- Socket.IO/Expressの2026年既知DoS修正版をtransitive dependency overridesで固定。
- Docker本番イメージからテスト・監査Markdown・開発用ファイルを除外し、配布ノイズを削減。
- 公開領域に混入していた監査用mock_result.htmlを削除。
