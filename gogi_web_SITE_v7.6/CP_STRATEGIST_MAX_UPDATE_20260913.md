# 2026-09-13 CP最高戦略版

CPを「機能を使うだけ」から、状況・期待値・残りターン・秘密目標進捗を統合して判断する戦略エンジンへ強化。

- 自分の秘密目標を、残りターンと必要回数から達成可能性・緊急度まで評価。
- 第10ターン以降は本人にも公開される現在順位を使い、首位時は生存・防衛、下位時は逆転期待値を重視。
- 偵察履歴の通常カード差分、HP、キル、過去の告発失敗だけから相手の秘密目標を確率推定。
- 相手の秘密目標・所持P・未偵察手札・準備OK状態など、本人に見えない情報は戦略判断に使用しない。
- 攻撃・防御・偵察・告発・回復を、得点期待値・生存価値・契約報酬・秘密目標進捗で比較。
- 特殊カードは終盤価値と温存価値を評価。2倍告発は同一相手への上位2仮説も利用。
- 1位予想は候補評価を確率化し、倍率と機会費用から賭け額を決定。
- 購入は買い溜めを避け、秘密目標・低HP・終盤の必要性を優先。
- 交換はカードの戦略価値を比較し、CP宛て提案も損得判定。成立後はその場で行動を再計算。
- 公開契約は防衛・標的集中・告発誘導など、現在状況に意味がある場合だけ提示。
- 戦略スコアが近い場合は小さな乱数差を入れ、毎回同じ手を機械的に繰り返さない。
- チャット自動送信は引き続き行わない。

完全な勝利保証は行わない。五疑戦は隠し情報と同時行動を含むため、相手の未来行動を確定できない。CPは見えている情報だけで期待値を最大化する。
