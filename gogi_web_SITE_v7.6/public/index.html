ルームコード--------
五疑戦ルール

5人固定・15ターン。 5人のプレイヤーが揃うと自動で開始します。最終ポイントが最も高いプレイヤーが勝利。HPは5、0で脱落、復活なし。他人のポイントと秘密目標は試合中非公開。

1ターン

  1. 会話・行動選択：最大10分。チャットしながら通常カード・特殊カード・対象を選択できます。
  2. 全生存プレイヤーが「次へ」を押すと10分を待たず同時処理します。
  3. 結果発表：最大1分。接続中の人間全員が「次へ」を押すと1分を待たず次ターンへ進みます。

放置対策：2ターン連続で一切操作がない場合は警告。3ターン連続で無操作の場合は自動脱落。カード指定が成功した場合、次ターンに使う通常カードと使用対象は固定されます。告発内容など本人が選ぶ必要項目を未選択のままタイムアウトした場合はサーバーが自動補完します。

通常カード

  • 攻撃：1ダメージ。防御を上回ってダメージが発生すると攻撃成功+10P。
  • 防御：自分または他の生存者1人を選び、その人への攻撃力1を防ぐ。実際に1以上防いだ場合、自分を守った成功は+10P、他人を守った成功は+15P。
  • 偵察：生存者・脱落者を問わず、自分以外の相手のHP・キル数・通常カード種類/枚数を自分だけ確認。特殊カード・ポイント・秘密目標は見えない。
  • 告発：相手の秘密目標を当てる。成功+25P、失敗-10P。成功時は対象の秘密目標を無効化。
  • 回復：自分または生存中の相手1人のHP+2（最大5）。同じターンに攻撃と重なった場合は回復を先に処理します。他人のHPを実際に1以上回復できた場合は+10P。

特殊カード

  • 完全防御：自分への全攻撃を防ぎ、攻撃者人数×10P。他人には使用できない。
  • 無効：指定相手のそのターンの通常/特殊行動を無効化。
  • カード指定：相手・次ターンに使わせる通常カード・そのカードを使う対象まで指定。相手が指定カードを持っていなければ失敗し、カード指定は使用者へ返却。指定した通常カードが指定対象へ成功した場合、その成功得点は指定者へ入る。告発失敗の-10Pなど失敗減点は指定者へ移らず、実際に行動した本人が受ける。異なる指定が同時に競合すると対象は次ターン行動なし。
  • ポイント泥棒：5〜25Pを指定して奪う。同じ相手への同時泥棒は5P単位で公平配分。
  • 2倍カード：攻撃2回（同一/別対象可） / 防御2回分 / 偵察2人 / 告発2回 / 回復+4。

会話中にできること

全体/個別チャット、カード購入、交換、公開契約、行動選択。ポイント譲渡・カード譲渡の独立機能は廃止し、プレイヤー間の資産移動は交換を使います。交換は双方ともポイント0P・カード0枚を選択でき、片側だけ資産を出す提案も相手が承認すれば成立します。両側とも0P・0枚だけの空交換はできません。交換・公開契約はいずれもターンを消費しません。同盟・嘘・ブラフ・裏切りはゲーム上の戦術として自由。

購入価格

攻撃15P / 防御15P / 偵察15P / 告発25P / 回復35P / 特殊カード（ランダム）45P。通常カード・特殊カードとも、所持ポイントの範囲で購入回数制限なし。

主な得点

攻撃成功+10P / 自分への防御成功+10P / 他人への防御成功+15P / 他人への回復成功+10P / 告発成功+25P / 告発失敗-10P / 秘密目標+25P / 15ターン生存+50P。単独キル・共同キルの得点はありません。第15ターンは攻撃成功・防御成功・他人回復成功・告発成功・告発失敗・完全防御などの得点/減点が2倍。秘密目標+25Pと生存+50P、ポイント泥棒や交換によるポイント移動は2倍対象外。第5ターン開始時+5P、第10ターン開始時+10P、第15ターン開始時+15Pをその時点の生存者へ固定付与します。第15ターン開始の+15Pも2倍になりません。第15ターン終了まで生存したプレイヤーには+50Pを固定付与し、これも2倍対象外です。

秘密目標は各プレイヤーが10種類から独立ランダム抽選します。同じ秘密目標が複数人に配られる場合があります。

秘密目標10種を見る
  1. 観察者：3ターン連続で偵察
  2. 追跡者：同じ1人を5回偵察
  3. 賭け師：告発相手を一度も偵察せず、その相手への告発成功
  4. 殺人鬼：3ターン連続で攻撃
  5. 死神：同じ1人を5回攻撃
  6. 鉄壁：防御を3回成功
  7. 耐久者：回復未使用
  8. 瀕死：累計5ダメージ以上を受けて生存
  9. 無防備：防御未使用
  10. 隠者：特殊カード未使用

耐久者・無防備・隠者は、第15ターンまで生存して未使用、または何ターン目でも未使用のまま脱落した時点で達成。

公開契約

第1〜15ターンに、20P刻みで使用Pを設定して全員に見える公開契約を件数制限なく提示できます。同じターンに複数件・同時に複数件の提示も可能です。通常は20Pなら達成者1人につき5P、40Pなら1人10P、60Pなら1人15P。第15ターンに判定される契約は最終ターン2倍で20Pなら1人10P、40Pなら1人20P、60Pなら1人30Pです。契約一覧・参加通知・受付終了通知などでは使用Pを表示せず、1人あたりの報酬額だけを毎回全員へ表示します。契約を出した本人は参加できないため参加者は最大4人です。参加しなかった人・未達成者の分など配り切らずに余ったポイントは契約を出した色へ返却されます。条件は「指定した色を攻撃」「契約を出した色を攻撃しない」「契約を出した色へ防御カードを使う」「指定した色を告発」の4種類。告発契約は告発の成功・失敗に関係なく、指定した色へ有効な告発を実行すれば達成。参加者が1人以上いれば原則次ターン終了時に自動判定し、第15ターンに提示した契約は同ターン終了時に判定します。参加者0人なら全額返却。

1位予想

第3・6・9ターンのいずれかで1試合1回だけ、最終的に1位になるプレイヤーを予想して5P刻みで所持Pの範囲内なら上限なく賭けられます。賭けたPはその場で差し引かれます。第3ターンは10倍、第6ターンは5倍、第9ターンは2.5倍。まず払戻し前順位で予想を判定し、その後に払戻しを加えて最終順位を再計算します。試合中は誰に・何P・何ターンで賭けたかを本人以外へ公開しません。試合終了時に全員の予想相手・賭けP・賭けターン・倍率・的中/外れ・払戻し額を全員へ公開します。最終順位には払戻し後のポイントが反映されます。

五戯チップ

五戯チップは無料のゲーム内チップです。課金購入・譲渡・換金・景品交換はできません。最初に100,000チップを所持し、所持チップが0になった場合のみ100,000チップをチャージできます。日付による自動配布はありません。公開マッチは0または100チップ刻みで賭け額を選び、同じ賭け額を選んだ5人だけでマッチします。プライベートマッチは部屋を作った人が賭け額を設定し、参加者も同額が必要です。必要チップを持っていない場合は参加できません。0チップなら賭けなしで遊べます。対戦開始時に全員から賭け額を差し引き、最終順位1位の賞金枠は賭け額の2.5倍、1位予想の成績1位の賞金枠も賭け額の2.5倍です。最終順位1位が同率の場合は最終順位賞金枠を均等分配します。1位予想は、的中者のうちゲーム内の1位予想払戻しPが最も高い人を予想成績1位とし、同率なら予想賞金枠を均等分配します。的中者がいない、または誰も1位予想をしていない場合は、予想賞金枠を第2順位発表（払戻し後の最終順位）の1位へ配分し、同率1位なら均等分配します。同じ人が両方で単独1位なら合計で賭け額の5倍を受け取ります。

勝敗

同点時は、キル数 → 告発成功数 → 有効な秘密目標達成数 → 生存ターン数 → 残りHP の順で判定。すべて同じなら同順位。

ゲーム終了後は、全ターンについて各プレイヤーが誰に何をしたか、その行動の成功・失敗、HP・ポイント変化などを「全ターン行動履歴」で全員に公開します。

詳細な秘密目標・得点・特殊処理はサーバー側の正式ルールに従います。
