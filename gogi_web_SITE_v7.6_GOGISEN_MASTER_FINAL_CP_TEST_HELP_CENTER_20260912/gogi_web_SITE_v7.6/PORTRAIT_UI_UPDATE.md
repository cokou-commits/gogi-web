# 縦一画面UI更新

- 会話・行動選択: 最大10分
- 結果表示: 最大1分
- 縦画面基準、ページスクロールなし
- 上中央: 五疑戦
- 左上: 色 / HP / ポイント / 10ターン目以降の本人順位
- 左上操作: 購入 / 譲渡 / 偵察履歴
- 右上: ターン / 残り時間
- 中央: 全体・個別切替チャット
- 下部: 通常カード5枚を横1列、特殊カード5枚を横1列
- カード枚数表示は「5枚」形式
- ルールは左下「?」から大画面表示
- 購入・譲渡・偵察履歴はオーバーレイ表示
- 偵察履歴はターン単位で保存表示
- 譲渡のカード選択肢には所持枚数を付けず、所持不足時は「カードが足りません」
- 結果フェーズは通常操作UIを隠し、結果だけを表示
