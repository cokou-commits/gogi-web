# 結果表示・カード指定UI更新（2026-09-12）

- ターン結果画面の「公開結果」「自分だけの結果」「ポイント増減」の3区分を廃止し、「結果」1区分へ統一。
- 結果画面には本人の通常カードの成功/失敗、本人の偵察結果、本人のHP純増減、本人のポイント純増減だけを表示。
- 他プレイヤーのターン結果は結果画面のstateへ送信しない。
- 防御1枚で2人から攻撃を受け、1回防いで1ダメージを受けた場合は「防御成功」「HP-1　ポイント+10」の形式で表示。
- カード指定中は「指定されているため、このカードしか使えません」と明示し、指定者の情報は表示しない。
- 公開契約は所持P以内・25P刻み。25Pなら達成者1人5P、50Pなら1人10Pで、余剰は契約主へ返却。
