# 五疑 v7.6 — 現行ルール決定事項

2026-09-11時点の現行仕様。

- 本番ルールは5人固定・人間のみ。**この確認テスト版だけ**空き枠をCPで補充可能。CPは外部AI/APIを使用しない。
- 秘密目標は10種類、5人へ重複なし配布。
- 攻撃成功+10P、防御成功+10P。
- 単独キル・共同キルの追加得点はなし。キル数自体は記録する。
- 告発成功+25P、告発失敗-10P。
- 秘密目標報酬+25P、15ターン生存+50P。
- 第15ターンは攻撃成功・防御成功・告発成功/失敗・完全防御などを2倍。秘密目標と生存ボーナスは2倍にしない。
- ポイント泥棒・交換によるポイント移動・秘密目標得点没収はポイント移動/回収なので第15ターンでも倍化しない。
- 告発成功で対象の秘密目標を無効化し、既得の秘密目標得点も没収。
- 情報発言機能は廃止。通常チャットのみ。
- 未使用系（耐久者・無防備・隠者）は、第15ターン生存で達成。何ターン目でも未使用のまま脱落した場合は脱落時点で達成。

## 秘密目標10種

1. 観察者：3ターン連続で偵察
2. 追跡者：同じ1人を5回偵察
3. 賭け師：告発相手を一度も偵察せず、その相手への告発成功
4. 殺人鬼：3ターン連続で攻撃
5. 死神：同じ1人を5回攻撃
6. 鉄壁：防御を3回成功
7. 耐久者：回復を使わない
8. 瀕死：累計5ダメージ以上を受けて生存
9. 無防備：防御を使わない
10. 隠者：特殊カードを使わない


## 1位予想ギャンブル

- 第3・6・9ターンのいずれかで1試合1回。5P刻みで所持Pまで。
- 第3ターン10倍 / 第6ターン5倍 / 第9ターン2.5倍。
- 払戻し前順位で的中判定し、払戻し後に最終順位を再計算。
- 賭け先・賭け額・賭けターン・的中/外れ・払戻しは本人以外へ非公開。

## 交換

- ポイント譲渡・カード単体譲渡は廃止し、資産移動は交換へ統一。
- 双方とも0P・カード0枚を選択できる。
- 片側だけが資産を出す提案も、相手承認で成立する。
- 両側とも0P・0枚の空交換だけは禁止。
- 交換はターンを消費しない。
- 未回答はターン終了時に自動キャンセル。

## 公開契約

- 第1〜14ターンに、5P刻み報酬を預けて1件提示可能。
- 条件・報酬・受諾者は公開。受諾は1人。
- 「指定相手を次ターン有効攻撃」または「次ターンに契約主を攻撃しない」を次ターン終了時に自動判定。
- 達成者には1人あたり契約ポイント÷5を配布し、未参加・未達成分など余ったポイントは契約主へ返却。
- 公開契約はターンを消費しない。
